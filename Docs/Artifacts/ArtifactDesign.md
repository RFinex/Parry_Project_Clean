# Parry Project 아티팩트 기획안

등급별 효과 32종과 빌드 조합 · 2026년 10월 27일

효과와 수치는 밸런스 테스트 후 확정한다. 원래 제안 수치를 유지한 기획 목록이다.

| 컨셉 | 전투 방향 |

| 맹공 | 패리를 줄이거나 포기하고 일반 공격과 콤보에 집중 |

| 처형 | 균형 파괴와 처형을 다음 적에게 연결 |

## 빌드별 조합 예시

| 빌드 | 핵심 조합 | 플레이 방식 |
|---|---|---|
| 패리 포기형 맹공 | 부러진 방패 + 연격의 고리 + 철혈의 박동 | 콤보를 완성하면서 대시로 생존 |
| 극단적 유리 대포 | 금 간 송곳니 + 피 묻은 계약서 + 광인의 가면 | 높은 화력으로 전투를 짧게 끝내기 |
| 패리 반격형 | 결투용 손목띠 + 반격의 문장 + 거울의 심판 | 패리 후 강화된 한 번의 공격 |
| 대시 공격형 | 추격자의 부츠 + 잔풍의 매듭 + 폭풍의 궤적 | 대시와 공격을 반복하며 위치 변경 |
| 저체력 역전형 | 붉은 실 + 잿불 심장 + 꺼지지 않는 심지 | 낮은 HP를 유지하며 위험 감수 |
| 처형 연쇄형 | 균열의 부적 + 형리의 사슬 + 찰나의 왕관 | 한 적을 무너뜨려 주변 적까지 연쇄 처형 |

## 계산과 효과 적용 규칙

- 일반 공격 피해는 기본 공격과 콤보에 적용한다. 모든 가하는 HP 피해는 일반 공격, 아이템 피해, 보스 처형 피해에 적용하는 설계안이다.
- 균형 피해는 HP 피해와 별도로 계산한다. 패리 불가 아이템을 보유하면 패리 강화 효과는 작동하지 않는다.
- 다음 공격 강화는 빗나가면 유지하고 명중할 때 소비하는 설계안이다. 별도의 유효 시간이 있으면 해당 시간이 우선한다.
- 현재 퍼센트 계산 규칙은 (기본값 + 고정값 합계) × 각 퍼센트 배율의 곱이다. +10% 두 개는 1.21배, -10% 두 개는 0.81배다.
- 이 목록의 원래 수치를 유지했다. 곱연산 중복 보유에서 공격력·이동 속도·패리 시간이 과도하게 증가하는지 테스트하고, 최소 쿨타임 등 제한은 별도로 결정한다.
- 스태미나 소모 방식은 미정이므로 스태미나 관련 효과는 제외한다. 조건부 효과는 별도 구현이 필요하다.
